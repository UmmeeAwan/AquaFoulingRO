## How this project uses the data

| Phase | Use |
| --- | --- |
| 1 | Extract, checksum, audit CSVs |
| 2 | Dual-schema adapters, validate/normalise, readiness (blockers remain) |
| 3 | Quantitative readiness; **separate** OCWD `s3sf` baseline forecast experiment |

Source files are not gap-filled, outlier-edited, or overwritten. Independent physical normalisation still requires explicit concentration/calibration and confirmed stage hydraulics — see `reports/phase2/normalisation_readiness.md`. Phase 3 does **not** claim those blockers are resolved.

### OCWD Phase 3 experiment (separate from synthetic)

- Target: source-calculated `s3sf` (no re-application of FilmTec TCF).
- Identity: `source_series_id` only (filename/stage semantics unresolved).
- Metrics: `reports/phase3/ocwd_metrics.json` — **not** pooled with synthetic metrics.
- Reference window labelled analytical / not proven clean.

## Synthetic primary benchmark (Phase 3)

Reproducible brackish / NaCl-equivalent demonstration data generated by
`poetry run aqua generate-synthetic` from `configs/synthetic_benchmark.yaml`
into `artifacts/synthetic/` (raw measurements separate from ground-truth latents).

Documented in `artifacts/synthetic/domain_assumptions.json`. **Not** a validated
seawater model. Synthetic performance does **not** establish plant accuracy.
